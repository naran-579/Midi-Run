# Midi Run
A custom MIDI keypad with switches, sliders, rotary encoders, neopixels and capacitive buttons

# What makes mine unique (hardware-wise)
- Tried some copper art
- Simpler keypad footprint
- Much more convoluted pcb layout

I would've added more but I ran out of IO  

# What makes mine unique (software-wise)
- Volume is now connected to the press
- A sort of glissando mode
- USB identity
- Actual circuitpy compatibility
